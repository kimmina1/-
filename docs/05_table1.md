차이가 가장 크게 나타난 변수 3개


<B-2>
1. n은 관측 수, %와 평균은 가중 추정치라는 것
n은 관측 수(비가중), % 및 평균은 복잡표본 가중 추정치입니다.

2. 연속형 변수를 어떤 통계량으로 요약했는지
연속형 변수는 가중 평균 (설계 기반 표준오차, SE)으로 제시하였고 범주형 변수는 관측 수(가중 백분율 %)로 제시하였습니다.

3. 집단 비교에 사용한 방법 (SMD 기준 포함)
모든 추정치는 층화(kstrata, 18개), 집단(psu, 263개), 가중치(wt)를 반영한 복잡표본 설계 기반 도메인 분석을 사용하였습니다.

4. 결측이 있었다면 그 처리 방식
결측값은 분석 대상에서 제외(NaN 처리)한 뒤 도메인 분석을 적용하였습니다.
